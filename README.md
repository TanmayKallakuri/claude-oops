# Claude Oops

Where Claude users gather to talk about what broke — with live Anthropic
uptime and a jumping-off point to the plugin marketplace.

Think: GitHub issues meets Reddit, scoped to Claude.

## Status

Phase 1 (foundations) — auth, profiles, test harness, CI.

## Stack

Next.js 15 (App Router) · Supabase (Postgres / Auth / Storage / Realtime)
· TypeScript · Tailwind · Vitest · Vercel
